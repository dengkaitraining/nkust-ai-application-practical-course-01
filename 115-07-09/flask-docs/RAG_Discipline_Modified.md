# **An Industrial Predictive Maintenance RAG Alert System Based on the Harness Engineering Framework**

- Large Language Models (LLMs) are capable of compressing large amounts of knowledge into high-dimensional parameters. However, their “closed parametric memory” structure can lead to hallucinations and insufficient knowledge timeliness, making them difficult to apply directly in industrial predictive maintenance (PdM) scenarios that require low fault tolerance.

This study develops a low-fault-tolerance alert system for industrial predictive maintenance based on a Retrieval-Augmented Generation (RAG) architecture. The system integrates Prompt Engineering, Context Engineering, and Harness Engineering, with Harness Engineering serving as the core mechanism for reliability control. The knowledge sources used by the RAG system include various types of IoT sensor data as well as experiential knowledge from senior maintenance experts.

Experimental results show that the proposed alert system achieves a 90% recall rate in predictive maintenance tasks. In addition, the local conversational system achieves an accuracy rate of 95% in intent classification tests. The contribution of this study lies in introducing Harness Engineering into the design of Agentic RAG systems as an engineering approach for reducing model hallucinations, controlling inference risks, and improving alert reliability in industrial settings. The results further indicate that, under the constraints and control of Harness Engineering, a small-scale local language model combined with a RAG architecture is feasible for industrial-grade, low-fault-tolerance tasks.

# ** Design and Implementation of a Drug Information Retrieval-Augmented Question Answering System Based on Drug Name Entity Verification **
- This study designs and implements a drug information retrieval-augmented question answering system based on drug name entity verification. To address the growing need for reliable drug information under aging societies and polypharmacy, the system integrates Large Language Models with a keyword-first retrieval architecture.

The proposed system uses query rewriting and key information classification to identify drug names, diseases, symptoms, and other query types. A Drug Name Entity Verification mechanism and Drug Gate mechanism validate candidate drug names through a PostgreSQL drug database, preventing incorrect entities from entering the retrieval process. The knowledge base integrates pharmacopeia data, package inserts, and patient education materials. Exact keyword matching is performed first, while BM25 retrieval serves as a fallback mechanism. Retrieved evidence is filtered before answer generation, and a LINE Bot interface enables real-time user inquiries.

Experimental results show strong performance in Faithfulness, Context Precision, Context Recall, and Factual Correctness. The findings indicate that drug name entity verification improves retrieval reliability, reduces hallucination risks, and enhances the practical applicability of drug information question answering systems.
